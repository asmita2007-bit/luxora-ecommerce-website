LUXORA E-COMMERCE WEBSITE
==========================

Open index.html in Google Chrome.

Main features:
- Premium responsive e-commerce homepage
- Home / Shop / Categories / Offers / About
- 20 products
- Search and sorting
- Category filtering: Fashion, Beauty, Footwear, Lifestyle
- Click any product to open full Product Details
- Size, color, quantity, stock and rating
- Wishlist
- Working shopping cart
- Coupon codes: WELCOME20 and LUXORA10
- Complete checkout
- Delivery address: name, mobile, house/flat, area, city, state, PIN and address type
- PIN delivery check
- COD / UPI / Card demo payment choices
- Order confirmation with Order ID
- Responsive mobile layout
- No server/database required; this is a front-end practical/demo website.
